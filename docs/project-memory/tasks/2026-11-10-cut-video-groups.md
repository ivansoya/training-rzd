Итог выкладки и текущий серверный каталог — [в отдельной записи](2026-11-10-release-voran.md). Ниже сохранены исходные результаты и границы предыдущей сессии.

## Принятый результат

- Общий блок всех нарезанных кадров расположен первым, присутствует только при наличии роликов `mode: cut`, по умолчанию свёрнут. В заголовке видны количество и состояния. При нуле кадров называется «Нарезанных кадров пока нет».
- Ролики разделены на «Нарезанные» (`frames > 0`) и «Ненарезанные». Пустые группы отсутствуют. У каждой группы собственные сворачивание, поиск и фильтр по тагам; у нарезанных — фильтр по состоянию разметки.
- Состояние кадров слева и остальные фильтры справа находятся в одной строке. На узком экране строка прокручивается внутри блока.
- Кадры каждого ролика можно раскрыть отдельно; доступны плитка/список, разделение на размеченные и неразмеченные, подгрузка страниц. Фильтры и вид сохраняются при сворачивании.
- Клик открывает настоящий редактор с навигацией по выбранной подборке. Кнопка «Смотреть кадры» и Enter раскрывают общую галерею, когда есть ролики на нарезку.
- Кадры с непроверенной разметкой модели остаются среди неразмеченных; подтверждённый фон считается размеченным. Удалённые кадры исключены из галереи.
- Сворачивание анимировано, учтён `prefers-reduced-motion`. На узких страницах таски используется существующая навигация полосой значков, паспорт переходит под основное содержимое.

## Структура изменения

Frontend:

- Новый `frontend/src/components/mag/tasks/CutFrames.tsx`: `FoldSource` для независимых сворачиваемых блоков, `FilterTags`, `CutFramesGallery` и `CutFramesCard`. Внутренний `useFrames` загружает страницы по 24 кадра при раскрытии, отменяет устаревшие запросы, поддерживает повтор и подгрузку.
- `Sources.tsx`: `CutCard` разделяет ролики на две группы `CutGroup`; `ReelRow` раскрывает галерею своего ролика. Запуск/очистка агента из меню ограничены видимыми роликами; при пустой выборке меню отсутствует.
- `TaskPage.tsx`: общий блок перед остальными источниками, загрузка выбранной подборки для редактора, вход из основной кнопки и Enter.
- `tasks.ts`: `cutCounts`, `reviewedCount`, `filterCutVideos`. Суммирование сохраняет совместимость с кешем, ещё не содержащим `reviewed`.
- `frontend/src/auth/api.ts`: `TaskImageQuery` расширен `review` и `tag_ids`; `getTaskImages` принимает `AbortSignal`; счётчики источников содержат необязательный `reviewed`.
- `MagShell.tsx`: страницы отдельных тасок используют существующий компактный rail при ширине меньше 760 px. `styles/layout.css`: оформление галереи, групп, фильтров и анимаций; одна колонка содержимого до 1180 px.

Backend:

- `backend/common/task_frames.py`: SQL-предикат `reviewed()` — `annotated`/`empty` без ожидающей проверки разметки.
- `backend/datasets_svc/task_routes.py`: `/api/tasks/<id>/counts` добавляет `reviewed` по источникам; `/api/tasks/<id>/images` поддерживает `review=new|done` и `tags` (OR внутри списка, пересечение с другими фильтрами). Сохраняется ограничение по таске и источнику, таги проверяются в пределах проекта.
- Параметры страниц валидируются, некорректные источники/состояния дают 400. В сортировку добавлен `Image.id`, чтобы одинаковые имена не нарушали пагинацию. Миграция БД не нужна.
